# Evaluation — 2026-09-10

One live Pi run compared supplied Slack and Notion pricing URLs. Two documented
Strale v2 GETs returned HTTP 200, each capped at $0.324. Total $0.00 paid and
$0.648 held, payment pending. No retry or extra page purchase occurred. Together
with the review test, three purchases had $0.918 exposure. Settlement is unverified.

The run checked the original official pricing pages separately from extraction.
Slack's provider response used USD while the captured page used EUR; no FX
conversion or direct cheapest ranking was made. Comparison-grid feature labels
were not accepted as proof of inclusion. Notion $10/$20 card prices were
source-identified as monthly equivalents billed annually; source data showed
$12/$24 monthly rates. Visible custom Enterprise pricing stayed unknown despite
hidden numeric amounts. These source checks happened in the original live run.

Both competitors were represented with raw prices, currency, unit, commitment,
source dates and unknowns. This supports one two-page comparison, not every
region, plan toggle, future price, or negotiated quote. Extractor delivery is
not independent price truth; same-locale source conditions remain necessary.

A no-skill Pi baseline used the same frozen saved provider/source evidence with
zero network data calls or purchases and also identified currency and billing
conflicts. This is a saved-data terminal-analysis comparison, not a controlled
acquisition benchmark or proof of causal skill improvement. The skill now calls
out the observed locale, active-toggle, feature-grid and hidden-price pitfalls;
no separate post-revision replay success is claimed.

An unpaid synthetic boundary did not rank a seat subscription against a
percentage-plus-fixed transaction fee without a common usage scenario. Synthetic
amounts were not attributed to Slack or Notion. Private account data is omitted.

Independent outcome review checked the cited original HTML and found no material
live-output correction required. The shared baseline packet also contained
extracted companion JSON with acquisition-agent interpretations, so neither arm
is a blind source-discovery test. This limitation prevents causal uplift claims.
The baseline's optional synthetic transaction example omitted the fixed fee
from its total. That isolated baseline error does not establish a statistical
winner or change the limits of this two-page comparison.
